02 / Live console

Start, stop, and send commands.

The live console shows output from the server process and takes commands. Start, stop, and monitor that process from the same place. The Minecraft EULA has to be accepted before a server can launch.

Install mods and modpacks.

Search Modrinth, then install, update, remove, or disable mods. A modpack is managed as a group, not as unrelated files. Downloads are validated, and checksum verification stays on that path.
